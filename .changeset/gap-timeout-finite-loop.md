The `oracle-gaps` directive for a `timeout` gap, and the design skill's `timeout` bullet in step 8, now give a way out of a loop in production's own code before calling it a CLI shortfall. When the loop's end rests on the arithmetic the mutant changed, rewrite the loop to walk something fixed before it starts, such as a list of what it will visit (every header end found first, then that list walked) or a bound fixed before the loop. No arithmetic in its body can then keep it going, so the mutant's run ends and a law can kill it. The rewrite is a production change, and the oracle judges it. Only where no such rewrite fits is the mutant reported as a known CLI shortfall.
