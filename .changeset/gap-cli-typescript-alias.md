The `oracle-gaps` CLI's TypeScript is now the npm alias dependency `typescript-for-tanstack-oracles` (`npm:typescript@^5.9.2`), and the CLI resolves it by that name. Before, the plain `typescript` dependency was hoisted by npm to an adopter's root. A project without TypeScript got a `typescript` package, and a project with its own TypeScript range could have that range deduped up to 5.9. Now neither happens. npm still links the alias's `tsc` and `tsserver` into `node_modules/.bin` in a project without TypeScript. After an incremental `npm install` of this package into a project with TypeScript, `.bin/tsc` points at the alias until a clean install (`npm ci`, or removing `node_modules`); a later plain `npm install` does not repair it. That is still strictly better than before, when the same incremental install raised the project's root `typescript` itself, for example from 5.4.5 to 5.9.3. On a clean install, the project's own `typescript` provides `tsc`. pnpm links only direct dependencies' commands, so it is not affected.
