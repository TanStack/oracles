The `oracle-gaps` report no longer offers dead code beside the missing law. The how-to in `summary.md` now calls code dead in its own last step, before the rerun, and names the evidence: a `dead-code` gap, or, for any other survivor, a law that decides the value exactly on every public entry point that reaches the code, with every kill kept by mutant key across the removal. The `dead-code` legend line says first that this class alone shows dead code, and that a survivor of any other class shows only that no law depends on its code yet. The skills and docs order the explanations of a survivor the same way.
