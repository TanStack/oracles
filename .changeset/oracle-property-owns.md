`oracleProperty` takes an `owns` list: the production files or functions (`src/x.ts`, `src/x.ts#fn`) whose static call tree the oracle owns. The `oracle-gaps` CLI reads `owns` from an object-literal argument of any call in a test file, so a wrapper that forwards `owns` to `oracleProperty` (`registerX('id', { owns: [...] })`) names it at its call. A test file that calls `oracleProperty`, or passes such a list, is an oracle file, and it owns the union of its lists. Every test file is read, because a file that never calls `oracleProperty` still owns code when it passes `owns` to a wrapper that it imports. An `owns` key inside an assertion's arguments is data, so it is not read: an `expect` chain (including `.not`, `.soft`, a computed matcher, and an aliased `expect`), `assert` and its members, `chai`, `expectTypeOf`, and `assertType`. An `owns` key in an object literal passed to any other call is read, so an unrelated domain object with that key makes the file an oracle file. An assertion library under a default or namespace import name, such as `import ok from 'node:assert'`, is read the same way. Each list must be a literal array of string or plain template literals. It refuses a run that has no oracle file, or in which no file owns a selected source, with one diagnostic. Before, such a run reported zero gaps without judging anything. `law.owner` is removed. Each run writes its output under `<package>/.oracle-gaps/out/<run>/` by default, not in a shared `/tmp/oracle-gaps`, and keeps the last five run directories. Add `.oracle-gaps/` and `.oracle-gaps-*` to `.gitignore`.
