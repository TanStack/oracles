`oracleProperty` takes an `owns` list: the production files or functions (`src/x.ts`, `src/x.ts#fn`) whose static call tree the oracle owns. The `oracle-gaps` CLI reads `owns` from an object-literal argument of any call in a test file, so a wrapper that forwards `owns` to `oracleProperty` (`registerX('id', { owns: [...] })`) names it at its call. A test file that calls `oracleProperty`, or passes such a list, is an oracle file, and it owns the union of its lists. An `owns` key inside an expectation's arguments, as in `expect(x).toEqual({ owns: [...] })`, is not read. An `owns` key in an object literal passed to any other call is read, so an unrelated domain object with that key makes the file an oracle file. Each list must be a literal array of string or plain template literals. It refuses a run that has no oracle file, or in which no file owns a selected source, with one diagnostic. Before, such a run reported zero gaps without judging anything. `law.owner` is removed. Each run writes its output under `<package>/.oracle-gaps/out/<run>/` by default, not in a shared `/tmp/oracle-gaps`, and keeps the last five run directories. Add `.oracle-gaps/` and `.oracle-gaps-*` to `.gitignore`.
