'@tanstack/oracles': minor
---

A failing law no longer blocks the gap report for its whole file. In `oracle-gaps`, a test of an oracle file that fails with no mutant active judges nothing: it is left out per test, as a nondeterministic test is, and the passing tests of its file still judge the mutants the file owns. A failing law still runs in every copy of its file: its calls count toward the copy's call budget, its I/O and timers toward idle, and it keeps its reach, but its verdicts judge nothing and it is never charged extra work. A count cut that a failing law causes blocks the mutant by that law. A test of a `describe` whose `beforeAll` or `afterAll` throws is a failing law too. An owner file that fails outside its tests (it does not load, or a file-level hook throws) judges nothing, and another owner file's passing tests still judge the mutants they share. A mutant that no deterministic passing owner test reached is `blocked` by its owners' failing laws that reached it, and by owner files that judge nothing; its directive names them. The baseline prints one `oracle-gaps: blocked` line per failing law, named by its file and test names (or one per broken file), `results.json` lists each failing file's `laws`, and the report stays provisional.
